# v0.62.0

## Summary
More of the standard library now enforces its documented behavior at run time, with new timekeeping and conversion helpers.

## Highlights

### Runtime-checked contracts across stats, conversion and math
kind: stdlib
Functions in the statistics, conversion and math modules now carry machine-checked contracts that verify their results while your program runs, catching wrong results close to their source.

### A monotonic clock you can rely on
kind: stdlib
xiom.time.monotonic_ms() returns a never-decreasing millisecond reading, so measuring elapsed time no longer breaks when the system clock is adjusted.

### Comparison and conversion helpers where you expect them
kind: stdlib
str_compare now resolves from xiom.string, and the integer to_string formatter from xiom.convert, so importing those modules is enough to call them.

### Reproducible release archives
kind: tooling
Stdlib release archives are now byte-for-byte reproducible, so published checksums stay stable when a release job is re-run.
