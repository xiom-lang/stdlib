# v0.62.0

## Summary
More of the standard library now checks its own results while your program runs, with a new monotonic clock for reliable timing.

## Highlights

### Runtime-checked contracts across the standard library
kind: stdlib
Functions in the collections, statistics, conversion and math modules now carry machine-checked contracts that verify their results as your program runs, catching wrong results close to where they happen.

### A monotonic clock for reliable timing
kind: stdlib
xiom.time.monotonic_ms() returns a never-decreasing millisecond reading, so measuring elapsed time no longer breaks when the system clock is adjusted.
