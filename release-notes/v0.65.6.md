# v0.65.6

## Summary
Ownership contracts for the JSON entry points, enabling the compiler to reclaim parse and builder trees, plus a permanent Float-to-Int128 coverage lock. No breaking changes.

## Highlights

### JSON ownership contracts
kind: stdlib
json_parse, json_stringify, json_pretty, json_escape and the builder build() carry the R3/R4 ownership contracts. A direct parse binding and a builder passed to stringify become reclaimable by the compiler, so repeated JSON work no longer retains the tree.

### Float to Int128 coverage locked
kind: stdlib
A permanent probe covers Float64, Float128 and Float32 to Int128 and UInt128, signed positive and negative. It fails on the pre-fix compiler and passes on the current pin, locking the numeric-conversion fix.

## Breaking changes
- None.

## Known issues
- The JSON memory reclaim needs compiler v0.65.6 or later; on v0.65.5 the contracts are inert and the old retention remains.
- Contract coverage remains partial in the documented no-clause tail.
- Verified against compiler pin v0.65.5.
