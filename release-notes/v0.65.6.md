# v0.65.6

## Summary
Confined blocks run faster and reclaim freed guard allocations, and ownership contracts now reclaim JSON trees and HTTP server parse buffers.

## Highlights

### Faster confined blocks and recycled guard allocations
kind: fix
The POSIX confinement trampoline no longer saves the signal mask on every confined entry, cutting the t3-hot-reload floor from 27 ms to 5 ms internal against peer Rust at 6 ms. Freed guard-arena blocks are recycled through size-bucketed free lists, so a balanced alloc and free loop inside one confined block stays flat.

### Ownership contracts reclaim JSON and server buffers
kind: fix
JSON parse and render carry ownership and borrow contracts so parse trees, builder containers and scratch buffers are reclaimed while literal keys and borrowed leaves stay untouched. The string builder to Str method borrows its buffer, and the HTTP server frees each parsed field scratch buffer after copying.

## Breaking changes
- None.

## Known issues
- The compiler drop-family residual for deeply aliased aggregates is compiler-side; this release addresses the direct parse and render trees.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
- Verified against compiler pin v0.65.5.
