# v0.65.6

## Summary
Confined blocks and guard allocation recycle faster, formatter heap corruption is fixed, and JSON parse/render ownership contracts reclaim their trees. No breaking changes.

## Highlights

### Confined blocks, guard recycling, formatter stability
kind: fix
The confinement trampoline cuts the t3-hot-reload floor to 5 ms internal, guard free lists recycle blocks without overrunning the next header, and bool/float string results are owned copies so returned literals are not freed. The formatter and network smokes are green.

### JSON and HTTP ownership contracts
kind: fix
JSON parse and render carry ownership and borrow contracts so parse trees, builder containers and scratch buffers are reclaimed while literal keys and borrowed leaves stay untouched. The string builder to Str method borrows its buffer; HTTP server fields are freed after copying.

## Breaking changes
- None.

## Known issues
- A rare request-builder string corruption in http_build_request is under compiler investigation.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
- Verified against compiler pin v0.65.6.
