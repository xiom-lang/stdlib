# v0.64.10

## Summary
Hotfix for JSON number rendering that pushes digits with an allocation-free byte loop, removing a crash in the HTTP and JSON service call chain on the pinned compiler without changing the public API.

## Highlights

### JSON number rendering hotfix
kind: fix
json_stringify, json_pretty, serialize.json_minify and number helpers render digits through _json_push_uint_digits instead of builder.sb_push_int, whose stack buffer miscompiled on the pinned compiler and crashed the HTTP and scatter-gather probes. Output stays byte-identical and the JSON gates stay green.

### Compiler pin unchanged
kind: stdlib
The hotfix keeps the compiler pin at v0.64.8 and changes no public signatures, so consumers move from 0.64.9 with no source changes.

## Breaking changes
- None.

## Known issues
- Contract coverage remains partial in the lazy iterator adapters, the legacy numeric module and parts of math and string.
- JSON build- and parse-side retention remains compiler drop-elaboration work.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
