# v0.64.5

## Summary
Consumes waves 114-139: the quadratic pass sweeps the string, escaping, encoding, hashing, parser and file-IO families to linear reads, new durability and server primitives land, and thread spawn results are byte-exact.

## Highlights

### Byte and string paths go linear across the tree
kind: stdlib
The strnlen and concatenate-per-item sweep converts the string, escaping, encoding, hashing, parser and file-IO families to cached single-pass reads and buffer builders. Hot loops use bounds-guaranteed slices, large payloads scale linearly, and every wave is locked by a probe.

### Thread spawn results are byte-exact
kind: fix
The spawn result buffer is main-heap and the runtime trampoline stores the full 64-bit result and done flag, so join readbacks return the exact worker value on every ABI. Acceptance: single and two-thread spawns print the exact results across repeated runs.
