# v0.65.5

## Summary
The standard library ships the persistent worker pool and real thread arguments, a flushed stderr diagnostics sink, lexical path normalization, and the last small Vec mutators. No breaking changes.

## Highlights

### Persistent worker pool and real thread arguments
kind: stdlib
thread.pool owns a persistent OS worker fleet with a bounded FIFO queue, a true join, and a shutdown drain. tp_submit_with runs f(arg) on a worker; thread.spawn_with is a real OS thread with its argument. Named or top-level jobs only. Probes p_wave_workerpool, p_wave145 and p_wave153.

### Diagnostics sink and path ergonomics
kind: stdlib
io.eprintln writes one flushed stderr line and io.flush_stderr exposes the explicit flush, so a later crash cannot lose the marker. io.normalize_path cleans separators and dot segments, and io.join_paths treats backslash as a separator. Vec gains swap_remove and a sort_by method. Probe p_engine_p1p2_gaps.

## Breaking changes
- None.

## Known issues
- The compiler drop-family residual still retains memory under repeated JSON build, parse and stringify; this is compiler-side.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands; it is gated on a macOS witness.
- Contract coverage remains partial in the documented no-clause tail (iter, os, math, thread, ffi, serialize, format).
- By-value functions passed where a by-reference function is required are accepted and misread the payload on v0.65.4; declare predicate parameters with a reference until fixed.
- Verified against compiler pin v0.65.4.
