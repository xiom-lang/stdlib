# v0.62.2

## Summary
The standard library's atomic operations are marked for direct compilation, so thread-safe code stops paying a per-call safety trampoline.

## Highlights

### Standard-library atomics run at native speed
kind: stdlib
Atomic integer, boolean, and pointer operations in the standard library's sync module now compile directly, removing the per-call safety trampoline from tight thread-safe loops built on them.
