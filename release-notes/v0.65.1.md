# v0.65.1

## Summary
Two standard-library read helpers now declare their returned Vec as caller-owned, letting the compiler drop the payload without changing the API.

## Highlights

### Owned return contracts for read helpers
kind: fix
io.read_file_bytes and io.read_at carry #[owns_return]: the Ok payload is a fresh main-heap Vec owned by the caller. Older pins ignore the attribute; the next compiler registers the payload for a scope-exit drop, removing the read-path Vec leak.

## Breaking changes
- None.

## Known issues
- Contract coverage remains partial in the lazy iterator adapters, the legacy numeric module and parts of math and string.
- JSON parse-side retention remains compiler drop-elaboration work; this release supplies the ownership contract that the next compiler uses.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
