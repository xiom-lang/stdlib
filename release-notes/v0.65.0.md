# v0.65.0

## Summary
Reusable receive buffers and a guarded Vec copy-out path land alongside the JSON number-rendering crash fix, with no public API breaks.

## Highlights

### Reusable receive buffers and guarded copy-out
kind: stdlib
socket_recv_into and socket_recv_timeout_into fill a caller-owned Vec and reuse its capacity, so per-connection read buffers stop allocating per request. The runtime also returns main-heap Vec buffers in place on confined-block exit, and JSON number rendering is allocation-free.

## Breaking changes
- None.

## Known issues
- Contract coverage remains partial in the lazy iterator adapters, the legacy numeric module and parts of math and string.
- JSON build- and parse-side retention remains compiler drop-elaboration work.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
