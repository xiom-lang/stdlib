# v0.65.2

## Summary
Byte-sized vectors now allocate by element stride, and the HTTP/2 primitive layer gains HPACK dynamic/Huffman and header-block reassembly, with no breaking changes.

## Highlights

### Packed Vec slot stride for byte buffers
kind: fix
Vec.with_len, push, reserve, shrink_to_fit and insert use the header elem_size (with the legacy 8-byte fallback) instead of a hardcoded 8. Vec[UInt8], Vec[Bool] and Vec[Char] become packed; with_len reads v.elem_size on the type receiver. A 4 MiB with_len byte buffer fits a 24 MiB cap in the combined compiler tree.

### HTTP/2 primitive layer
kind: stdlib
The pure h2 primitives add the RFC 7541 dynamic table, the full Huffman codec (H=1 string decode/encode), and HEADERS plus CONTINUATION reassembly. These are standalone helpers; the connection state machine is not included.

## Breaking changes
- None.

## Known issues
- Contract coverage remains partial in the lazy iterator adapters, the legacy numeric module and parts of math and string.
- The packed stride is exercised with the compiler vec_slot_size companion; older pins over-allocate but remain compatible.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
