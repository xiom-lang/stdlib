# v0.65.7

## Summary
Fixes the formatter heap corruption and bounds guard free-list zeroing, plus JSON parse and render ownership contracts so repeated work reclaims its trees. No breaking changes.

## Highlights

### Formatter and guard stability
kind: fix
Bool and float string results are now owned copies, so returned literals are no longer freed on scope exit; guard free-list reuse zeroes only the payload, not the next block. The formatter and network smokes are green again on the compiler pin.

### JSON ownership contracts
kind: fix
JSON parse and render carry ownership and borrow contracts so parse trees, builder containers and scratch buffers are reclaimed while literal keys and borrowed leaves stay untouched. The string builder to Str method borrows its buffer.

## Breaking changes
- None.

## Known issues
- A rare request-builder string corruption in http_build_request is under compiler investigation; it is not in the formatter path.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
- Verified against compiler pin v0.65.6.
