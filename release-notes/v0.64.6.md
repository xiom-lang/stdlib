# v0.64.6

## Summary
The campaign release: in-tree TLS sessions, the dynamic-Huffman deflate encoder, zero-copy send and popen spawn, an SSE connection layer, the fix-first defect batch, and a wishlist sweep of 17 new modules.

## Highlights

### In-tree TLS sessions
kind: feature
The session driver over the eight-symbol contract is live end to end with a minimal system-libssl backend (skip-safe when libssl is absent), plus server-half helpers, an error taxonomy and fd-readiness pumps. The ecosystem route remains the published ssl package.

### Compression upgrades
kind: feature
Dynamic-Huffman deflate encoding and dynamic-block read completion with public RFC 1951 tables, a neutral CRC32 and Accept-Encoding negotiation. ZIP container read/write verifies CRC-32 per entry and is cross-checked against the reference implementation.

### Zero-copy send and popen spawn
kind: feature
sendfile/TransmitFile plus writev behind a checked socket send-file wrapper; non-blocking spawn with pipes, popen and pclose, argv spawning and a real wait status.

### SSE connection layer
kind: feature
Connect, drain and close server-sent-event streams over live sockets with response-head validation and honest error paths.

### Fix-first defect batch
kind: fix
INT64_MIN printing and parsing, the 64-bit logical shift at 63 bits (now public helpers), the BLAKE2b tail load and bit-rotation sign corrections, and runtime host-platform branches for path and directory helpers.

### Wishlist sweep
kind: stdlib
Seventeen new modules: fixed-point math and integer stats, string views, ASCII and codepoint helpers, strict parsing, little-endian codecs, keyed mailboxes, event-log cursors, bit sets, composite keys, vec helpers, XML tokens, zip, Keccak-256, FNV-1a, glob and a non-aborting assertion catalog.

## Breaking changes
- None.

## Known issues
- Still open: inline Result payload indexing in concat contexts; builtin Mutex shadowing; a bare trailing match after a Vec push.
- Still open: method calls on fields typed with non-bare module-qualified type spellings; use bare leaf type names.
- Still open: a runtime 128-bit division inlined into a vector-loop function can crash; the shipped fixed-point helpers use a shift and mask long division instead.
- Still open: scalar hash identity shadowing from the builtin.
