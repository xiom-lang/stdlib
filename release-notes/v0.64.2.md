# v0.64.2

## Summary
Stdlib pin moves past v0.64.1: the iter clause surface is unblocked, file writes are byte-exact, and coverage rises to 57.7% with new serialization, bench and format clauses.

## Highlights

### Iter contracts unblocked
kind: stdlib
The closure-thunk clause leak is gone on the new pin: Range.count and the retried range set (contains, sum, product, collect, count, max, min, find, all, any, nth, last) carry contracts again, and the iter smoke family passes at high parallelism.

### Byte-exact file IO and CRLF-clean line reads
kind: fix
write_file, append_file and write_file_bytes open in binary mode, so newlines are never rewritten when writing on Windows; read_file_lines strips a trailing carriage return so CRLF files parse cleanly. Both carry regression locks.

### Coverage and ecosystem intake
kind: stdlib
Pub-with-clause coverage rises to 57.7% (serialize 90.3%, convert 94.1%, bench 87.5%, format 39.0%). Consumer-lane relays from the web, database, vector and bindings lanes are tracked in docs/STDLIB-WISHLIST.md.

## Known issues
- Geom matrix tuple-element inference, polyhedra hulls, clause-position float vec indexing and the ensures is-ok guard remain open; each is re-filed with fresh v0.64.1 evidence.
